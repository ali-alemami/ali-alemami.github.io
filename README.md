# ali-alemami.github.io

Personal portfolio website for Ali Alemami, hosted via GitHub Pages.

## Live Site

[https://ali-alemami.github.io](https://ali-alemami.github.io)

## Contents

- `index.html` — Main portfolio page
- `style.css` — Stylesheet
- `profile-pic.png` — Profile image
- `Ali_Alemami_CV.pdf` — Downloadable CV

## Technologies

- HTML5, CSS3
- Google Fonts (Inter, JetBrains Mono)
- Hosted on GitHub Pages

## Local Preview

Open `index.html` directly in a browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
